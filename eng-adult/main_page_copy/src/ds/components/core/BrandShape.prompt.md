Decorative brand element (cross, chevron, concentric rings, starburst) for section corners and hero backdrops.

```jsx
<BrandShape shape="rings" size={180} opacity={.25} style={{position:'absolute',right:-40,top:-40}}/>
```

Use one or two per section, bleeding off an edge, never as content. Colours come from `--element-orange`, `--element-hot-orange`, `--element-yellow`, `--element-tint`.
